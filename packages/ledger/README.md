# @eng/ledger

XRPL transaction helpers, Testnet websocket selection (`TESTNET_ENDPOINTS`), repo-root and `DATA_DIR` resolution, the Privy signer at `@eng/ledger/privy`, and `DecideRequest` / `DecideResponse` at `@eng/ledger/decide`. The Testnet helpers are also exported at `@eng/ledger/testnet`.

It is private. A packed tarball contains `dist/`. In this repository the `source` export condition loads `src/`.
