# N2A storyboard and shot list

Recording map for the silent cut. The times below are the edited cut, not the wall clock. Live waits are removed: faucet setup, the RLUSD AMM buy, the hotel `AccountDelete` age wait, the wait until check-in, and the wait until `confirmBy`. The cut is 1:52. Start each source recording at the banner named below.

Script lines stay on screen. The opening card, shot 6, the lower thirds, and the end card are the only text that is not a script line.

This page replaces the old beats M1, M2, M4, D2, D6, D8. Those names are beats. They are not the decision ids D1, D2, and D6. H8 is not a shot either.

H8 (arbiter silent, chargeback) is not in `npm run demo:hotel-dispute`. A 60-second `rulingWindow` is below `minRulingWindow` `259200s` (`policies/hotel@2.0.0.json:31`). The committed hotel policy keeps `rulingWindow` at `432000s` (`policies/hotel@2.0.0.json:30`). Putting a 60-second window on a deal would need a co-signer change. This storyboard does not ask for that.

Commands, in order:

```bash
npm run demo:x402:t54
```

```bash
COSIGNER_TICK_SUBMIT=1 COSIGNER_TICK_MS=10000 npm run cosigner:local
npm run demo:hotel-dispute
```

The hotel command is Clip 3. Leave the co-signer running. `COSIGNER_TICK_SUBMIT=1` is what submits the H2 refund (`packages/cosigner/demo/hotel-dispute-testnet.ts:9`).

## What must not be said

The opening card and the end card use the README first-screen sentence, with XRPL named in front: `XRPL Testnet reference implementation; not for mainnet funds.` The README sentence is `Testnet reference implementation; not for mainnet funds.` (`README.md:3`).

Do not say the hotel token is Ripple's RLUSD. The hotel script sets `CUR` with `currencyHex('RLUSD')` and a faucet issuer it creates (`packages/cosigner/demo/hotel-dispute-testnet.ts:39`). That string is not passed to `say`. The walkthrough states the same limit (`docs/demo/hotel-dispute.md:22`). The t54 clip pays Ripple's Testnet RLUSD issuer `rQhWct2fv4Vc4KRjRgMrxa8xPN9Zx9iLKV` (`packages/cosigner/demo/x402/facilitator.ts:8`). Those are different assets. Shot 6 is the card for that.

Clip 1 shows a 1.00 payment inside a 100/day cap being signed. The SIGN line prints B8 and W6 only. Clip 2 is where the cap is proved.

The H2 narration says the local co-signer submits `default.refund`. Do not say "our service", and do not describe the local co-signer as a hosted product.

Narration notes are facts for Naor to write over. They are not copy for the screen. Lower thirds are the short cards listed in the shot.
