# T28 session kit

Do not run sessions until the root README quickstart's last step is an MCP client config whose command is `eng-mcp` and the tester's own agent makes the payment. `npm run demo:mcp` does not open this gate.

This file is for the person running the session. It is not linked from the README. The tester uses only the [README](../../README.md).

## Recruiting

TS/Node; has used an MCP client; hasn't seen the repo; at least one with no XRPL experience; own machine; ideally one who builds agents that pay.

Facilitator note, not part of the brief: the machine needs Node >= 22.13.

## Tester brief

Say this, and nothing more about the steps:

> Goal: using only the README, get an AI agent to make a spending-capped payment on XRPL Testnet. Please think out loud. We won't help unless you're stuck for more than 5 minutes; if you are, tell us and we'll note it. Stop at 30 minutes either way.
